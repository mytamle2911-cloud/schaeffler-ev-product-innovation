# E-Guard product concept and experience

## Device proposal
An inline safety adapter between an electrical outlet and compatible charging equipment, with a hardware sensing/control concept monitoring current, voltage, temperature and electrical leakage.

## App proposal
Live charge-state visibility, alerts, scheduled charging, history and energy-use suggestions.

## Conceptual user journey
1. User installs a compatible adapter through an appropriate qualified process.
2. User starts charging and views current status.
3. Monitoring logic flags abnormal readings.
4. User receives an alert; device response depends on validated engineering requirements.
5. User reviews usage history in the app.

## Safety caveat
The proposal's protective strategies require hardware design review, compatibility assessment, regulatory certification, fail-safe testing and clear installation guidance. Nothing in this repository is an installation instruction or evidence that a commercially safe device has been built.
